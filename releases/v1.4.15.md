# Codex Meter 1.4.15

- **Задачи без типа заметны в списке.** Контрастная плашка помогает найти записи, которым нужна классификация.
- **Фильтр «Без типа · N» в один клик** показывает все такие задачи, сбрасывая прежний поиск и фильтры. Повторный клик возвращает весь список.
- **Массовый выбор включается иконкой списка с галочками** рядом с переключателем задач и запусков. По умолчанию чекбоксы скрыты; включённая кнопка подсвечена. Выключение снимает отметки и сохраняет открытую карточку.

Просмотр карточки по-прежнему сохраняет накопленный выбор. Статусы задач меняются только человеком; история, оплаты и привязки сохраняются.
