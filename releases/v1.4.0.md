Codex Meter now checks for signed updates from GitHub Releases.

- Update reminders in the menu bar and Notification Center.
- Review release notes and install from the app; automatic checks can be disabled.
- Signed update feeds and Ed25519-authenticated archives, checked before extraction.
- Universal Apple Silicon and Intel build.
- Release gates cover accounting, native UI and real installation/relaunch on isolated data.

This is the first updater-enabled release. Users of 1.3.2 and earlier must install it
manually once. Current releases are not notarized by Apple; macOS may require per-app
approval on first launch. Task and payment data remains in Application Support.
