# Codex Meter 1.4.11

- **Единый справочник типов.** Типы создаются, переименовываются и архивируются в настройках. В задачах, массовых действиях и фильтрах используется выбор из этого справочника.
- **Явная классификация.** Скилл больше не назначает тип автоматически. Задачи без подтверждённого типа и их запуски помечаются; тип можно указать сразу для нескольких задач.
- **Точные фильтры.** Фильтр выбирает конкретный тип или задачи без типа. Переименование типа обновляет отображение во всех связанных задачах и сохраняет фильтрацию по его идентификатору.
- **Сохранение истории.** Старые значения остаются для справки, но требуют подтверждения выбором из списка. Запуски, платежи и назначения сохраняются. Архивирование типа не удаляет его из истории.
- **Прогноз по подтверждённым данным.** CLI использует явно выбранный тип; без него не подбирает похожие задачи по имени скилла.
