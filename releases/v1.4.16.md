# Codex Meter 1.4.16

- **Быстрее сохраняются изменения.** Действия с задачами больше не ждут завершения фонового разбора больших журналов. Устаревший результат импорта не заменяет только что сохранённые данные на экране.
- **Исправлена лишняя блокировка базы.** Открытие существующей базы для чтения больше не выполняет запись версии схемы. CLI может читать данные, пока приложение сохраняет изменения.
- **Ускорен пересчёт расхода.** Распределение квоты обрабатывает запуски по времени вместо повторного просмотра всей истории для каждого снимка. Убрано повторное чтение запусков при сохранении.
- **Понятнее названия запусков.** Если журнал подтверждает сжатие контекста без нового запроса пользователя, запуск называется «Сжатие контекста Codex». Исторические записи уточняются при импорте доступных журналов; токены и привязки сохраняются.

Статусы задач по-прежнему меняет только человек. Обновление сохраняет задачи, оплаты и историю; отдельный сервер базы данных не требуется.
