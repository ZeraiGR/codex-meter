# Codex Meter 1.4.14

- **Статус задачи меняете только вы** в карточке или через массовое действие. Агент не завершает, не приостанавливает и не открывает задачи заново.
- Ожидание ответа, завершение работы агента, новый запуск и переключение между задачами сохраняют их статусы и даты завершения. Учёт запусков продолжается отдельно.
- Старые команды `task-end` и `task-pause` возвращают ошибку без изменений. `task-resume` связывает запуск с задачей, сохраняя её статус.

История задач, оплаты и привязки сохраняются. Для новых инструкций агенту обновите отдельно установленный скилл интеграции по руководству проекта.
