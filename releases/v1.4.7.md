# Codex Meter 1.4.7

- **Выбор больше не теряется при промахе.** Клик по карточке открывает переписку, сохраняя все отмеченные запуски. Флажок меняет только одну отметку.
- **В флажок проще попасть.** Область нажатия увеличена до 44 × 44 точек. Отметки видны независимо от открытой переписки.
- **Сохранение накопленной группы.** Стрелки, Esc и отмена назначения не сбрасывают отметки. Для снятия всех отметок есть отдельный крестик. Назначение одного открытого запуска сохраняет остальные отметки.

История задач, оплаты и привязки сохраняются при обновлении.
