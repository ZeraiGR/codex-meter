# Codex Meter 1.4.4

- Несколько запусков можно выбрать и назначить одной существующей или новой задаче. Сохранение выполняется целиком, а скрытые фильтром запуски исключаются из выбора.
- Стоимость задач показывается также в USD по курсу ЦБ РФ. Сохранённый курс доступен без сети и помечается при устаревании.
- Предварительные сроки восстановления квоты отличаются от подтверждённых данных сервера. Изменение недельного срока сопровождается временем наблюдения.
- Ошибки авторизации, ограничения частоты и сетевые сбои при получении квоты различаются; автоматические повторы замедляются при сбоях.
- В исходники включён отдельный Telegram-бот: лимиты, напоминания, несколько диалогов Codex, переключение сессий и доступ к Bot API через SSH-туннель. Бот требует отдельной настройки по `docs/telegram.md`; установка приложения не создаёт и не привязывает бота автоматически.

История задач, оплаты и привязки сохраняются при обновлении приложения.
